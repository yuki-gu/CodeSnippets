## 構成ファイル
### Python
- **cui_stopwatch.py**

  標準出力に時間経過を表示するストップウォッチです。
  
  技術メモ : print出力時に文字列の先頭に"\r"(キャリッジリターン)を付加すると、以前出力した文字列を上書きして出力できる
  
  作成背景 : CUIの進捗表示バーの表示の仕組みを調査し、キャリッジリターンの使い方をテストするサンプルアプリとして作成
- **log_mouse_key.py**

  マウスとキーボードの入力内容を標準出力に記録するソフト。

  記録対象 : mouse (left|right|middle) (up|down), key keyname (up|down)

  機能詳細 : 起動時に記録開始、Ctrl+Cで記録終了

  技術メモ : print_event関数で表示形式を指定可能

  注意 : ChatGPTで作成したためコードの全てを精査していません。動作確認はしましたが、不適切な動作が混入する可能性があります。
